## 📖 О проекте

**Esharq** — это сборка [Equicord](https://github.com/Equicord/Equicord) с арабской локализацией; сам Equicord является форком [Vencord](https://github.com/Vendicated/Vencord).

### Чем отличается Esharq

- ⚡ **Высокая производительность** — собственные оптимизации для более быстрой и лёгкой работы
- 🌐 **Полная арабская и английская локализация** — переведены описания всех 300+ плагинов; язык переключается в настройках (применяется после перезапуска)
- 🔧 **Эксклюзивные доработки** — плагины и правки от нашей команды, которых больше нигде нет
- 🧩 **Более 300 плагинов** — все оригинальные плагины Equicord плюс эксклюзивные арабские
- 🔒 **Проверенная безопасность** — полный аудит безопасности, ноль уязвимостей в зависимостях
- 🔄 **Постоянные обновления** — ежедневная синхронизация с Equicord

Присоединяйтесь к сообществу: **[discord.gg/QamdqDNEDa](https://discord.gg/QamdqDNEDa)**

> Все сборки — на странице [**релизов Esharq-Installer**](https://github.com/LOSTSTR/Esharq-Installer/releases/latest).

---

### 🪟 Windows

Скачайте **EsharqInstaller.exe** и запустите — установщик сам найдёт Discord и установит Esharq.

### 🍎 macOS — Apple Silicon и Intel

Скачайте `.zip` для вашего процессора, распакуйте и запустите **EsharqInstaller**.
> ⚠️ Приложение не подписано — в первый раз откройте его через **правый клик → Открыть**.

### 🐧 Linux

Скачайте **EsharqInstaller-x11** (или `-wayland`), сделайте файл исполняемым и запустите:
```bash
chmod +x EsharqInstaller-x11 && ./EsharqInstaller-x11
```

Поддерживаются Ubuntu/Debian, Fedora/RHEL, Arch Linux, Flatpak и Snap.

## 🌐 Переключение языка

В Esharq встроено переключение между **арабским и английским**.

1. Откройте **Настройки Discord → Esharq**
2. Включите или выключите **«Arabic Mode»**
3. **Перезапустите Discord** — настройка помечена как `restartNeeded`, и Discord сам предложит перезапуск

> Язык фиксируется на время сессии намеренно: часть строк вычисляется при первой загрузке модуля, а часть — при отрисовке, поэтому переключение «на лету» оставило бы интерфейс наполовину арабским, наполовину английским. Перезапуск заставляет все переводы отрисоваться на выбранном языке.
>
> Когда Arabic Mode **выключен**, все описания плагинов возвращаются к английскому.  
> Подписи настроек внутри окон плагинов подчиняются той же настройке.

## 🛠️ Сборка из исходников (Devbuild)

### Требования

- [Git](https://git-scm.com/download)
- [Node.JS LTS](https://nodejs.dev/en/)

### Шаги

**1. Установите pnpm**

> Этот шаг может потребовать прав администратора (admin/root). После установки закройте и снова откройте терминал.

```shell
npm i -g pnpm
```

> ⚠️ **Важно:** не используйте терминал с правами администратора на следующих шагах — это может повредить установку Discord.

**2. Клонируйте репозиторий**

```shell
git clone https://github.com/LOSTSTR/Esharq
cd Esharq
```

**3. Установите зависимости**

```shell
pnpm install --frozen-lockfile
```

**4. Соберите проект**

```shell
pnpm build
```

**5. Внедрите Esharq в Discord**

```shell
pnpm inject
```

**6. Соберите веб-расширение (необязательно)**

```shell
pnpm buildWeb
```

После сборки найдите ZIP-файл в папке `dist` и загрузите его как расширение в браузер.

> Примечание: расширение для Firefox требует [Firefox for Developers](https://www.mozilla.org/en-US/firefox/developer/).
